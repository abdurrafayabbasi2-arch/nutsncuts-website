📖 Isko Save Aur Print Kaise Karein? (Step-by-Step)

Option 1: Apnay Computer / Printer Se (1-Click)
  1. Oopar "A4: Front Stickers" ya "A4: Back Stickers" tab per click karein.
  2. Oopar right per "🖨️ Print / Save PDF" button dabayein (ya keyboard se Ctrl + P).
  3. Printer mein "Save as PDF" select kar k file save kar lein, ya direct apna color printer select karein.
  4. Paper Size: A4 aur Scale: 100% (Default) rakhein.
  5. A4 Sticker Paper per print kar k scissor se cut karein aur pouches per chipka dein!
Option 2: Printing Shop / Press Walay Ko Bhejna
  1. Dono cards k neechay "💾 Save Image (PNG)" button dabayein, high quality image aap k Downloads folder mein save ho jayegi.
  2. Aap k computer ki D: drive per bhi sticker-front.svg aur sticker-back.svg saved hain.
  3. Yeh image ya SVG file WhatsApp ya USB k zariye kisi bhi printing shop walay ko dein aur kahein: "A4 sticker sheet per yeh print nikaal dein".
